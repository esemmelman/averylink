# Avery Links

Public link: https://esemmelman.github.io/averylink/

Immediately opens Avery Steinberg Menu in a new tab and requests focus, then replaces the original tab with Hebrew Vowel Match.

Allow pop-ups for https://esemmelman.github.io to enable both pages to open. The browser ultimately controls tab focus.

Static HTML and JavaScript; published with GitHub Pages from the root of main.
